## تفاصيل كل دفعة

### A — إعدادات النشر
- `main.py`: `docs_url/redoc_url/openapi_url = None` حين `APP_ENV=production`.
- `next.config.mjs`: ترويسات لكل المسارات (HSTS في الإنتاج فقط، nosniff، `frame-ancestors 'none'`/XFO، Referrer-Policy، Permissions-Policy، `Content-Security-Policy-Report-Only`).
- الـAPI: `nosniff` و`Cache-Control: no-store` للاستجابات المصادَق عليها؛ تضييق `allow_headers` إلى القائمة المستخدمة فعلًا.
- شعار المنصة: `private`.
- **القبول:** اختبارات تتحقق من الترويسات ومن 404 للتوثيق في الإنتاج.

### B — ذرّية التدقيق
- الخدمات (`create_organization`, `change_status`) تتوقف عن `commit`؛ المسار يسجّل التدقيق ثم `commit` واحد.
- `PUT /storage`: تدقيق `organization_storage_quota_changed` (قبل/بعد، الفاعل، request_id).
- **القبول:** فشل محقون في التدقيق يُلغي العملية؛ اختبار وجود سجل الحصة.

### C — العزل
- `tests/security/test_cross_tenant_<module>.py` لكل من: procurement, shipping, masterdata, notifications/announcements, delegations, approvals, reports/exports, files.
- fixtures موحّدة: منظمتان وهميتان + مستخدمان بصلاحيات كاملة؛ لا بيانات حقيقية.
- حالات لكل مورد: GET/PATCH/DELETE/actions بمعرّف المنظمة الأخرى، مراجع عابرة في الإنشاء، البحث والفلترة والتصدير، تنزيل المرفقات.
- **حارس التغطية:** يقرأ `app.routes` ويقارن كل مسار مستأجر بمعامل `{…_id}` مع سجل التغطية؛ يفشل عند مسار جديد غير مغطى.

### D — جلسات المنصة
- تعميم فحص `sid` على `get_current_platform_account`؛ `PLATFORM_SESSION_MAX_HOURS` (افتراضي 8)؛ `PLATFORM_IDLE_TIMEOUT_MINUTES` (افتراضي 10) في واجهة المنصة؛ جلسة واحدة لكل حساب منصة (قابلة للضبط)؛ «جلساتي» وتنبيه جهاز جديد بالبريد. إعدادات مركزية في `config.py` لا قيم مبعثرة.

### E — MFA
- أعمدة: `mfa_secret` (مشفّر بمفتاح من البيئة)، `mfa_enabled_at`، جدول رموز استرداد (hash). 
- تدفق: كلمة مرور → توكن مرحلي (5 دقائق، `token_type=mfa_pending`، لا يُقبل في أي مسار آخر) → رمز TOTP أو رمز استرداد → جلسة.
- التسجيل الإلزامي عند أول دخول بعد التفعيل؛ نافذة ±1 خطوة؛ منع إعادة استخدام نفس الرمز.
- استرداد: Root يعيد ضبط MFA لحساب آخر (مع تدقيق وإشعار للحساب)؛ Root الأخير يستخدم رموز الاسترداد أو أمر CLI على الخادم.

### F — إعادة المصادقة والصلاحيات
- `require_recent_auth(minutes=5)`؛ مسار `POST /platform/auth/reauth` (رمز MFA).
- صلاحيات جديدة: `platform:organizations:archive`، `platform:organizations:quota`، `platform:organizations:root_recovery` (Root افتراضيًا).

### G — النسخ الاحتياطي
- `scripts/backup.sh` (pg_dump -Fc + أرشيف uploads، تشفير، تسمية بالتاريخ، احتفاظ)، `scripts/restore_verify.sh` إلى قاعدة **مؤقتة منفصلة**، `docs/operations/BACKUP_AND_RECOVERY.md` بالإجراء وRPO/RTO المقاسة. لا لمس لقاعدة الإنتاج.

### H — CI
- workflow: backend (pytest SQLite + Postgres service)، frontend (tsc, eslint, vitest, node test, build)، `npm audit --audit-level=high`، `pip-audit`.
- ترقية next/sharp ضمن نسخة متوافقة ثم تشغيل كامل.

### I — الأداء
- استعلام مجمّع + صفحات/بحث خادمي لقائمة المنظمات ولوحة المنصة.

### J — الشفافية
- إشعار مدير المنظمة (بريد + داخلي) لإجراءات المنصة على منظمته.
