# خارطة جاهزية SaaS المستقبلية — توثيق فقط

لا تنفيذ في هذه الجولة. IORP نظام أعمال تشغيلي أولًا؛ لا حاجة لتوسيع تجاري قبل إغلاق P0.

| المستقبل | نقطة التوسع القائمة | المخاطر والشروط قبل التنفيذ |
|---|---|---|
| اشتراكات وفوترة | Platform organization ID | فصل lifecycle التشغيلي عن subscription/payment؛ عدم ربط انقطاع السداد بحذف أو أرشفة آلية. |
| بوابة دفع | خدمات Platform | webhook موثوق وidempotency وتسوية؛ لا أسرار بطاقات داخل وحدات الأعمال. |
| onboarding آلي | PlatformOrganizationService وOrganizationProvisioningInterface | إعادة المحاولة دون duplicate org/root، تتبع تعطل SMTP؛ لا بناء workflow engine الآن. |
| خطط وentitlements | permissions وحصة التخزين الحالية | الصلاحية تحدد من يفعل، entitlement يحدد الخدمة المتاحة؛ لا تحويل role إلى خطة. |
| خدمة ذاتية للعميل | organization profile الحالي | فصل مسؤول العميل عن مسؤول المنصة؛ نقل ملكية الجذر إجراء حساس مستقل. |
| تحليلات استخدام | logs وملكية المنظمة | تجميع غير حساس، quotas مدروسة، لا تجميع مبيعات العملاء افتراضيًا. |
| دعم بموافقة العميل | Platform/Tenant identity boundary | تفويض محدود بمدة وسبب وقراءة افتراضية وإلغاء فوري؛ لا انتحال غير مقيد. |
| تصدير وحذف احتفاظ | registry التقارير وعلاقات المنظمة | تصدير يشمل الملفات وmanifest، retention قانوني مستقل؛ لا hard-delete تلقائي. |
| عزل بنية تحتية متقدم | واجهات core وorganization_id | قياس الحاجة أولًا؛ RLS أو schema/db منفصلة قرار لاحق مع backfill وحماية pool. |
| توسع أفقي وتوزيع منظمات | scheduler/renderer/session storage | rate limit مشترك، تخزين ملفات مشترك، فحص وظائف idempotent وpool capacity؛ لا توزيع جغرافي الآن. |

## حدود المعمارية المحفوظة

قاعدة المعاملات المشتركة ليست عيبًا بذاتها. الشركات المستقلة يمكنها مشاركة البنية مع عزل صحيح واختبارات ودفاعات مناسبة. لا نعد بعزل DB مستقل أو امتثال رسمي. مستقبل استعادة شركة منفردة يتطلب map للملكية الصريحة والموروثة والمراجع العامة وآثار audit والملفات؛ لا يكفي WHERE organization_id لكل جدول.

## معيار الانتقال إلى التوسع

عدد الشركات والحمل وتكلفة التشغيل ومتطلبات الاستعادة والامتثال تقود القرار. لا نضيف جداول plans/billing أو واجهات اشتراكات أو impersonation لمجرد الاستعداد للمستقبل.
